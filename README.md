# 📊 Sales Analysis Dashboard – Power BI

## 📌 Project Overview

This project is a **Sales Report 2024- Analysis Dashboard** developed using **Microsoft Power BI** to analyze sales performance, revenue, profit, products, customers, and other key business metrics.

The dashboard transforms raw sales data into interactive and meaningful visualizations that help businesses understand their sales performance and make data-driven decisions.

---

## 🎯 Project Objectives

* Analyze overall sales and revenue performance
* Track key business KPIs
* Identify top-performing products and categories
* Analyze sales and profit trends over time
* Understand customer and regional performance
* Identify areas of growth and improvement
* Build an interactive and user-friendly Power BI dashboard

## 🧹 Data Preparation

The raw data was prepared using **Power Query**.

Major data preparation steps included:

1. Removed duplicate records
2. Handled missing/null values
3. Corrected data types
4. Cleaned and standardized columns
5. Created required calculated columns
6. Prepared data for analysis
7. Established relationships between tables
